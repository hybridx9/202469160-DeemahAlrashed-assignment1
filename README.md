# Personal Portfolio
This is my personal portfolio website created for Assignment 1. It includes information about me, my projects, interests, and a contact form.

## Features
The website includes an About Me section, two projects with images, an Interests section, and a Contact section. It also displays a greeting based on the current time and uses a responsive layout for different screen sizes.

## Technologies Used
HTML, CSS, and JavaScript were used to create the website

## Setup
Clone or download this repository
Open the project folder
Open `index.html` in a web browser
